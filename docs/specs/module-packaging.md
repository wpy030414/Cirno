# Spec — 分发与打包（MSI + 依赖自举）

## 要构建什么

一个可在干净 Windows 11 机器上直接安装运行的 **MSI**。安装过程中若发现缺失的系统级依赖，
不是报错退出，而是**提供一键安装**；安装完成后继续原流程。

不做：自动更新、应用商店分发、跨平台包。

## 行为

### 依赖矩阵

| 依赖 | 是否随包 | 处理方式 |
|---|---|---|
| .NET 10 运行时 | 是（自包含发布） | 打进 MSI，用户无需安装 |
| Windows App SDK 运行时 | 是（自包含） | 打进 MSI，用户无需安装 |
| VC++ 2015–2022 x64 运行库 | 否（系统级共享） | 检测 → 缺失则引导安装官方 redist |
| WebView2 运行时 | 不需要 | 产品不使用 WebView2 |
| `claude` / `codex` CLI | 否（用户自装） | 首次启动检测，给出安装指引，不阻塞安装 |
| Windows 11 22000+ | 否 | 低于该版本时 Mica 自动降级为纯色，不阻断安装 |

**关键取舍**：自包含发布把「缺 .NET」「缺 WinAppSDK」这两类最常见的安装失败消灭在打包阶段，
剩下的真正系统级依赖只有 VC++ 运行库一项，引导成本可控。

### 安装流程

1. **前置检查**（在文件复制前）：
   - 读注册表判断 VC++ x64 运行库是否已安装；
   - 已安装 → 继续；
   - 未安装 → 弹出任务对话框：`立即安装` / `跳过（可能无法启动）` / `取消安装`。
2. **一键安装**：以静默参数运行随包的 `vc_redist.x64.exe`，等待结束，重新检查；
   成功则继续安装，失败则展示错误码与手动下载地址。
3. **文件落地**：安装到 `Program Files\Cirno`，写入开始菜单快捷方式（附带 AppUserModelID，
   供任务栏与通知识别）。
4. **收尾**：注册卸载项与图标；创建用户数据目录（`%LOCALAPPDATA%\Cirno`）留给首次启动。

### 静默安装

- `msiexec /i Cirno.msi /qn` 时**不得弹出任何 UI**：缺依赖直接失败退出并写入日志说明原因。
- 提供属性 `SKIPPREREQ=1` 跳过检查（给已自行装好依赖的用户/自动化用）。
- 安装日志：`/l*v` 标准 MSI 日志即可，不额外造日志格式。

### 卸载

- 删除安装目录与快捷方式、卸载项。
- **默认保留** `%LOCALAPPDATA%\Cirno`（会话数据库、provider 配置、凭据引用）。
- 属性 `REMOVEDATA=1` 时一并清理用户数据（需显式传参，不在 UI 里默认勾选）。

## 输入 / 输出

**输入**

- 发布产物：`dotnet publish` 的自包含输出目录。
- 随包依赖：`vc_redist.x64.exe`（微软允许随应用再分发）。
- 版本号：单一来源（构建脚本注入 MSI ProductVersion 与应用版本）。

**输出**

- `Cirno-<version>-x64.msi`：单文件、per-machine、可静默、可升级。
- 可选的 `.wixpdb` 符号文件（本地保留，不分发）。

## 约束

- 必须 per-machine 安装（写入 Program Files、需要管理员权限）。
- 主版本升级用 MajorUpgrade，禁止同版本重装导致的双实例。
- 安装/卸载期间若应用在运行，需先请求关闭，不得强杀（强杀会丢会话状态）。
- MSI 内不得包含任何网络请求；依赖安装只用随包二进制。
- 安装包必须可在离线机器上完成安装（除 CLI 安装指引外）。
- 用户数据与安装目录严格分离，卸载不误删。

## 边界条件

- 无管理员权限 → 安装器明确提示需要提权，不静默失败。
- 磁盘空间不足 → 安装前检查并给出所需空间。
- 旧版本正在运行 → 提示关闭后重试，或由安装器发送关闭请求并等待。
- VC++ 安装器返回 3010（需要重启）→ 视为成功但提示重启。
- 安装包未签名 → SmartScreen 警告属预期，正式分发前用受信证书签名。
- 用户系统已是更高版本的 VC++ 运行库 → 不降级、不覆盖。

## 验收标准

- [ ] 干净 Windows 11（无 .NET SDK、无 VC++ 可再发行包）上双击 MSI 可完成安装并启动。
- [ ] 缺失 VC++ 运行库时，安装器给出「立即安装」并能自动完成，随后继续安装成功。
- [ ] `/qn` 静默安装在缺依赖时快速失败且日志可定位原因。
- [ ] 覆盖安装升级到新版本后，用户会话数据完好。
- [ ] 卸载后安装目录清空、快捷方式移除，用户数据默认保留。
- [ ] 安装包内所有文件路径无绝对路径泄漏、无构建机路径。

## 完成定义

在一台从未装过开发工具的 Windows 11 机器上，只需该 MSI 与网络（装 CLI）即可跑通一次完整会话；
缺依赖时用户不需要自行搜索下载链接。
